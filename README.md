# UTMパラメータ生成ツール

Googleビジネスプロフィールからの流入や、イベント・院内掲示物のQRコードからの流入を、
Googleアナリティクス（GA4）で分けて計測するためのURLとQRコードを作るツールです。

## 設計方針

**このファイルには特定の医院の情報を一切含めていません。**
医院名・ホームページURL・略称は、利用者が初回に入力し、
そのパソコンのブラウザ内（localStorage）にのみ保存されます。外部へは送信されません。

そのため、URLやファイルが第三者に渡っても、どの医院が使っているかは分かりません。

## 特徴

- 単一HTMLファイル。外部への通信は一切ありません（CDN・フォント・API なし）
- QRコード生成は外部ライブラリを使わず自前実装（バージョン1〜40、誤り訂正L/M/Q/H）
- 用途プリセットと入力チェックで、命名の表記ゆれを防ぎます
- Google広告のリンク先に使わないよう、gclidを検出して生成を止めます

## 使い方

1. ページを開くと「最初に設定してください」の画面が出ます
2. 医院名・ホームページのURL・医院の略称を入力します（1回だけ）
3. 以降は用途を選んでURLとQRコードを作ります

設定を変えるときは、画面右上の「設定を変更」を押します。

## 命名規則

- 使える文字：半角小文字の英数字・ハイフン（-）・アンダースコア（_）
- 単語の区切りはハイフン、キャンペーン名の意味のまとまりの区切りはアンダースコア
- 例：`example_event-mannaka-fes_202609`

## 保存データについて

| キー | 内容 |
| --- | --- |
| `utm-builder.clinic.v1` | 医院名・ホームページURL・ホスト名・略称 |

保存形式を変更するときは、末尾のバージョン番号を上げてください。
